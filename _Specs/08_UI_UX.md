# 08 — UI / UX

## Current Needs
The prototype needs clear UI for:
- active skill
- cooldowns
- player health
- enemy health
- hover/target highlight

## Skill UI
Desired bottom-right skill display:
- current selected skill icon/name
- F8 Holy Bolt
- F10 Holy Rain
- right-click cast hint
- cooldown overlay

## Targeting Feedback
Targeting should show:
- enemy outline on hover
- possibly enemy nameplate
- enemy health bar
- selected target indicator

## Health Bars
Enemy health bars should:
- stay fixed to camera
- hide on death
- not rotate awkwardly
- be readable but not intrusive

Player health should be:
- bottom-left or bottom-center
- clear and persistent
- eventually include mana/energy/resource

## Readability Rules
Avoid:
- too many floating UI elements
- huge health bars
- overly bright effects
- particle spam

Need:
- readable enemies
- visible projectiles
- clear AoE indicators
- obvious selected skill
