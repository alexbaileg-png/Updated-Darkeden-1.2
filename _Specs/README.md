# DarkEden-Inspired ARPG Project

## Project Summary
This project is a dark gothic isometric ARPG inspired by the faction-war feeling of DarkEden, modernized with smoother controls, clearer combat, better readability, less mandatory level grind, and a stronger focus on PvP, builds, gear, and faction identity.

## Current Prototype
The current Unity prototype is focused on proving core combat feel before expanding into full game systems.

Current working systems:
- Click-to-move player movement
- Hold-left-click movement updates
- Right-click skill casting
- Holy Bolt projectile
- Homing Holy Bolt when enemy is highlighted/targeted
- Holy Rain AoE skill
- Enemy chase AI
- Enemy health and death state
- Enemy spawning
- Basic health bars
- Hover/target detection experiments
