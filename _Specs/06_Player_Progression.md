# 06 — Player Progression

## Philosophy
Leveling should exist but should not be the main wall between the player and fun. Players should unlock core abilities quickly. Long-term progression should come from gear, builds, PvP mastery, and faction systems.

## Leveling Direction
Target:
- early levels fast
- core kit unlocked early
- max level not too far away
- post-level progression through gear/builds

## XP Sources
Possible XP activities:
- killing enemies
- completing events
- faction objectives
- dungeons
- PvP assists/kills
- world bosses
- exploration

## Stats
Possible core stats:
- Strength
- Dexterity
- Intelligence
- Faith
- Vitality
- Willpower

Slayer/healer likely scales with:
- Faith
- Intelligence
- Vitality
- Willpower

## Gear Progression
Gear should be the main long-term grind.

Gear qualities:
- Common
- Uncommon
- Rare
- Epic
- Relic
- Mythic

Gear stats:
- damage
- cast speed
- cooldown reduction
- health
- resistances
- movement speed
- skill modifiers

## Skill Points
Players should earn skill points through:
- leveling
- quests
- faction ranks
- rare unlocks

Skill customization should support:
- damage upgrades
- alternate behavior
- PvP utility
- support variants
- hybrid builds
