# 10 — Roadmap

## Milestone 1 — Combat Sandbox
Goal: prove basic ARPG combat feel.

Status: In Progress

Requirements:
- click-to-move
- hold-click movement
- enemy chase
- player ranged attack
- homing Holy Bolt
- Holy Rain AoE
- enemy health/death
- spawning
- basic targeting

## Milestone 2 — Player Survival
Goal: make enemies dangerous.

Tasks:
- PlayerHealth script
- enemy attack logic
- player damage feedback
- player death state
- respawn system
- basic UI health bar

## Milestone 3 — Skill UI
Goal: show active skill and cooldowns.

Tasks:
- bottom-right selected skill UI
- F8/F10 display
- cooldown overlay
- skill icon placeholders
- selected-skill frame

## Milestone 4 — Loot and XP
Goal: add progression reward loop.

Tasks:
- XP gain on kill
- level-up event
- basic loot drops
- item pickup
- simple gear stats

## Milestone 5 — Enemy Variety
Goal: make combat less repetitive.

Tasks:
- melee enemy
- fast enemy
- ranged enemy
- tank enemy
- elite enemy modifier

## Milestone 6 — First Playable Demo
Goal: small polished arena demo.

Requirements:
- player health
- multiple skills
- enemy waves
- loot drops
- basic UI
- restart/respawn
- 5-minute gameplay loop
