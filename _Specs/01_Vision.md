# 01 — Game Vision

## Core Pitch
A dark gothic isometric ARPG where asymmetric factions fight for territory, rare gear, and PvP dominance. The game should capture the danger and faction identity of older PvP MMOs while using modern ARPG controls and smoother combat.

## Inspiration
Primary inspiration:
- DarkEden
- Diablo II: Resurrected
- Path of Exile
- Lost Ark
- Older open-world PvP MMOs

## Design Pillars
### 1. Faction Identity Matters
Factions should not feel cosmetic. Each faction should have different:
- combat style
- progression flavor
- visual language
- movement identity
- strengths and weaknesses
- PvP role

### 2. Fast Access to Fun
Players should not need hundreds of hours before the game becomes fun. Leveling should exist, but the best long-term progression should come from:
- gear
- build mastery
- PvP experience
- faction reputation
- player skill

### 3. PvP as Long-Term Content
The endgame should be driven by player conflict:
- faction wars
- contested zones
- territory objectives
- rare drops
- guild politics
- revenge and rivalry

### 4. Strong Build Variety
The game should allow unusual but viable builds. A healer should be able to become a damage-focused PvP threat. Players should discover strange, powerful combinations.

### 5. Readable Dark Visuals
The game should look dark and gothic, but combat must remain readable. Spell effects should be satisfying without creating visual clutter.

## What This Game Should Avoid
- excessive mandatory leveling grind
- pay-to-win systems
- daily chore checklists
- generic faction design
- bloated MMO UI
- particle spam
- meaningless gear upgrades
