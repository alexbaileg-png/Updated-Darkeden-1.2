# 02 — Core Gameplay Loop

## Current Prototype Loop
1. Player moves through a test arena.
2. Enemies spawn.
3. Enemies chase the player.
4. Player attacks with selected skill.
5. Enemy takes damage.
6. Enemy dies and remains briefly as a corpse.
7. More enemies spawn.

## Desired Short-Term Loop
1. Enter combat zone.
2. Identify enemy targets.
3. Use selected skills.
4. Avoid enemy attacks.
5. Kill enemies.
6. Collect loot or XP.
7. Upgrade gear/skills.
8. Push into harder content.

## Desired Mid-Term Loop
1. Choose activity:
   - enemy farming
   - faction event
   - PvP zone
   - dungeon
   - world boss
2. Earn rewards:
   - gear
   - crafting material
   - faction currency
   - skill unlocks
3. Improve build.
4. Test build in PvP or harder PvE.

## Desired Endgame Loop
1. Build optimization
2. Territory conflict
3. PvP ranking
4. Rare gear hunting
5. Guild/faction coordination
6. Seasonal events
7. Boss farming and contested objectives

## Design Note
The game should not feel like PvE is just a boring requirement before PvP. PvE should feed PvP through gear, resources, reputation, and zone control.
